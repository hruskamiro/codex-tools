# Codex Tools

**A small local toolkit for working with Codex.** Manage separate profiles,
browse and search past conversations, create work summaries, and run
reproducible structured tasks.

Codex Tools is an independent project and is not affiliated with or endorsed by
OpenAI.

## What can I use it for?

- **Read agent responses in real time** with polished typesetting in a private
  local browser viewer.
- **Typeset technical answers** with polished math, tables, and code blocks.
- **Find something you discussed before** across local Codex JSONL history.
- **Create daily and weekly work summaries** and browse them as a static site.
- **Keep multiple Codex logins separate** while optionally sharing conversations.
- **Move a login to another machine** with passphrase-encrypted profile exports.
- **Run schema-constrained tasks** with saved prompts, results, and token usage,
  through Codex CLI or a **separately authenticated ChatGPT-plan connection**.

## Quick start

**Requirements:** Linux or macOS, Python 3.10 or newer, and pipx. Viewing and
search need no model; model-backed summaries and structured tasks need Codex CLI.

```bash
pipx install git+https://github.com/hruskamiro/codex-tools.git
codex-tools alias install  # optional: ct and Bash completion
ct viewer
```

Without the alias, use `codex-tools` instead of `ct`. Standalone `codex-viewer`
and `codex-manager` commands are also installed. **Completion covers every
current top-level tool and its subcommands.**

Upgrade a GitHub installation with `pipx upgrade codex-tools`, then restart any
running viewer or relay. See [installation and updates](docs/installation.md)
for completion setup, editable installs, and older macOS support.

## Conversation viewer

**Read and search conversations in your browser**, with Markdown, math, code,
and linked attachments. The launcher opens a searchable conversation picker:

```bash
ct viewer
ct viewer launcher
```

Press **T** to switch Markdown/LaTeX, **L** to jump to the last message, and
**Shift-L** to open a chooser in a new tab. **S** toggles Auto sync; Manual shows
a badge for new messages. **R** refreshes in place; **Shift+R** refreshes and
jumps to the last message. Background checks stay still.

![Codex Viewer showing the symmetry of Riemann zeta zeros](docs/assets/codex-viewer-riemann-symmetry.png)

Generated by the real viewer from the included
[Riemann zeta symmetry example](docs/examples/riemann-symmetry.jsonl).
See the [viewer guide](docs/viewer.md) and [sync controls](docs/viewer-sync.md).

### Optional LaTeX view

**Typeset technical answers** as PDFs with high-quality equations, tables,
prose, and highlighted code. Install XeLaTeX on the rendering machine:

```bash
sudo apt install texlive-xetex texlive-latex-extra fonts-texgyre fonts-paratype fonts-dejavu-core
ct viewer doctor
ct viewer --set-default-latex
```

**Nothing breaks without LaTeX.** Markdown remains available. For relay
conversations, the default `auto` backend uses local XeLaTeX when available,
otherwise the peer's renderer. PDFs are cached for later offline reading.
See [LaTeX setup and remote rendering](docs/viewer.md#optional-latex-view).

## Agent Console and remote connections

**Read, message, and control live agents** from the terminal, including agents
on other machines:

```bash
ct agents
ct agents show SESSION
ct agents send SESSION "Check the tests and report back."
ct agents ui
```

The **Agent Console** keeps drafts, delivery receipts, and cached conversations.
SSH connections recover after interruptions; accepted messages use durable
queues. **Relay auto-start requires explicit destination permission and client
opt-in.** See [console controls](docs/agent-console.md) and
[relay/SSH setup](docs/relay.md).

## Profile manager

**Keep logins and configuration separate**, with shared conversations by
default or a private store using `--isolated`:

```bash
codex-manager new work
codex-manager run work
codex-manager install work
```

**The default wrapper is the profile name, with no added prefix.**

**Exports are encrypted by default.** Transfer a
login and configuration, optionally including conversations:

```bash
codex-manager export work
codex-manager import work.codex-profile --install
codex-manager update work.codex-profile
```

`update` imports or refreshes a profile and installs its wrapper by default,
preserving existing conversations. Use `--no-install` for login/configuration only.
Export with `--no-passphrase` only for an explicitly unencrypted
transfer: the resulting file contains plaintext credentials.

See [profiles and encrypted transfer](docs/profiles.md) for sharing, custom
wrapper names, renaming, and wrapper reinstallation with `update`.

## Search and activity

**Search is local and read-only.** Find text or list recently active conversations:

```bash
ct search "JSONDecodeError"
ct search "render failure" --here --context-turns 2
ct activity --last 2h --here
```

See [search and activity](docs/search-and-summaries.md#search) for time ranges,
working-directory filters, tool output, and JSON results.

## Summaries

Create Markdown summaries and browse them as a static site:

```bash
ct summary today
ct summary week --last-week
ct summary site --open
```

**Daily and weekly settings are independent.** Preview context without calling
a model using `ct summary today --show-context`; see the
[summary guide](docs/search-and-summaries.md#summaries) for settings.

## Structured tasks

**Run isolated, tool-free tasks under a strict JSON Schema**, retaining prompts,
results, events, and usage for reproducibility:

```bash
ct structured run --prompt prompt.txt --schema response.schema.json \
  --run-dir runs/example-001 --model MODEL
ct structured batch batch.json --batch-dir runs/batch-001
ct structured check runs/batch-001
```

**Batches default to one job and adaptive pacing.** Rate limits trigger a cooldown;
parallel batches reduce concurrency and recover gradually, up to `--jobs`.
Use `--fixed` to keep concurrency constant while retaining cooldowns.

The default backend uses `codex exec`; the optional **app-server backend uses a
separate authenticated connection** with **compact task instructions, no tools,
and an empty workspace** to reduce prompt overhead. See
[structured tasks](docs/structured-tasks.md) for login, usage snapshots, and pacing controls.

## Upcoming mobile Agent Console

**A companion mobile app for working with agents is being prepared for release.**
The mobile Agent Console is a separate project, and its integration is still in
development. Codex Tools provides optional support for it:

- **Voice transcription:** an optional service for dictation ([setup](docs/voice.md)).
- **Phone pairing:** temporary QR invitations and the phone's own SSH identity.
  See [pairing and authorization](docs/phone-pairing.md).
- **Mobile PDFs:** portrait and wide blocks with offline caching.
  See [mobile PDF reading](docs/mobile-pdf.md).

**These integrations are optional.** Normal installation adds no Whisper
libraries or models; voice and agent connections are configured independently.

## Configuration and diagnostics

```bash
ct config show
ct config edit
ct config validate
ct diagnose
```

Settings live in `~/.config/codex-tools/config.toml` (or under
`$XDG_CONFIG_HOME`). `ct config path` prints the location; `config edit` opens
`$VISUAL` or `$EDITOR` with a commented template on first use.

## Privacy and safety

- **Search and viewing are read-only.** Remote workflows use explicitly paired peers.
- **The viewer binds to `127.0.0.1` by default** and has no remote authentication.
- **Profile exports contain credentials.** Keep the encrypted bundle and passphrase private.
- **Destructive cleanup asks first.** Profiles use a trash area unless explicitly purged.

See [SECURITY.md](SECURITY.md).
